# Nick Post - Portfolio

Personal portfolio site showcasing my work as a Founding Product Designer with 12+ years of experience.

## Live Site

https://ncspost.github.io/Posty.design

## Features

- Responsive landing page built with Next.js 16 and Tailwind CSS v4
- CV/Experience section with full work history
- Case studies for Sutro 2.0 and Orchest
- Dark mode support
- Static export for GitHub Pages deployment

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
```

Static files are output to the `out` directory.

## Deployment

The site automatically deploys to GitHub Pages on push to the `main` branch via GitHub Actions.
